# Mensajes de commit

Cuando generes mensajes de commit:

- La descripción debe estar en español.
- Mantén el formato Conventional Commits.
- Mantén los tipos en inglés: `feat`, `fix`, `refactor`, `perf`, `test`, `docs`, `chore`, `build`.
- La descripción debe ser breve y clara.
