# Mi primera Skill

Cuando el usuario pida analizar un archivo:

1. Identifica el archivo que se debe analizar.
2. Explica brevemente qué vas a revisar.
3. Analiza su contenido.
4. Enumera los problemas o puntos importantes encontrados.
5. Después del análisis, si el usuario solicita una modificación,
   realiza el cambio directamente.
6. Explica qué modificaste.
